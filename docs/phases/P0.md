## Synthetic rig session `p0-synth-20261122` (53 runs; `bench/sessions/p0-synth-20261122/`)
Roles pinned to disjoint cores on this WSL2 laptop (generator 0-2, mock 3-4, gateway 5-6); runs 15 s after a 3 s warm-up; order randomized; mock restarted per run so each run sees only its own ground truth. **0/53 valid** (dispatch-lag p99 > 200 µs on every run; three direct runs at 1000 req/s also > 60 % generator CPU), so these are shape only.

- **Pre-flight (strict):** coordinated-omission and mock-jitter checks pass; generator-headroom and clock-join fail strict (host timers), as before. Noise-canary baseline captured for this host (`bench/noise-baseline.json`; synthetic).
- **Floor (event delay, merged p50 / p99; direct → null):** 250 req/s: 71/279 µs → 213/647 µs. 500 req/s: 65/463 µs → 390/8495 µs. 1000 req/s: 62/4971 µs → 8983/36575 µs. The null proxy's knee on its pinned cores is between 250 and 500 req/s at 64 events (≈ 1.2 busy cores); beyond it latency is dominated by queueing.
- **Fit:** see AMD-014 (unsaturated runs only; the all-runs fit gives R² < 0 and is shown only for transparency in `analysis.md`).
- **Transport/TLS:** AMD-013. h2c on both sides gave an erratic, heavy tail; TLS cost was within noise.
- **Burstiness:** at the same mean 500 req/s the synthetic bursty trace gave request-total p99 12.7 s vs 0.63 s for Poisson: arrival burstiness, not mean rate, decides the tail; the trace replay path works end to end (the trace is synthetic, see `bench/data/README.md`).
- **Ground-truth control:** 22 229 streams checked, 4 438 injected spans, **4 438 leaked** (pass-through), **0 benign streams altered**, 0 parse errors.

## What the harness found about itself (value of doing Phase 0 first)
0. **Sampling bias (AMD-011):** the shared stream-sampling hash gave 5-35 % for a requested 10 %; spotted because joined-event counts did not scale with `-emit-sample`. Fixed and regression-tested; the first batch of local results was discarded and regenerated.
1. **Proxy bug (AMD-005):** passing the inbound request body into the outbound transport truncated ≈ 0.5 % of long concurrent streams. Found through `twload`'s error accounting (`stream_truncated`) and the proxy's per-kind error counter; fixed, regression-tested.
2. **Generator can silently under-offer (AMD-007):** a pinned generator used to keep working through a backlog of past-due arrivals and report a calm run. Now the window is hard-bounded and unsent arrivals invalidate the run.
3. **Timer resolution matters more than expected (AMD-006):** forced a spin-margin design and a `twload timer` pre-flight step.
4. **Toolchain hygiene (AMD-003, AMD-004):** `govulncheck` flagged 29 stdlib issues in Go 1.26.0 → pinned 1.26.11; `staticcheck` flagged deprecated `x/net` h2c/http2 → migrated to `http.Protocols`.
5. **Proxy request-target hardening:** golangci-lint's SSRF finding prompted a test, which showed the null proxy would forward an absolute-form request line (`GET http://evil.example/x`) to its configured upstream; it now refuses any non-origin-form target with a 400 (no open-proxy behaviour; `TestRejectsNonOriginFormTargets`).
6. **Provenance:** `git_dirty` now means "tracked files differ from HEAD" (Go's build stamp counted untracked files, marking every result dirty).
